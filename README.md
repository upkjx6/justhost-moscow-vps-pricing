## 带宽是 fair-share，不是独享

官网每个套餐的端口后面都跟了一句 `fair-share`。300 Mbit/s、400 Mbit/s、750 Mbit/s 是共享带宽下的可用速率，不是给你拉满的独享通道，高峰期同一台物理机上的邻居跑得凶，你能分到多少要看当时情况。

“不限流量”对应的月度折算量（300 Mbit/s 标 93+ TB、750 Mbit/s 标 232+ TB）是这么算出来的，属于“只要不在跑满速”的上限说明，不是承诺。对建站、跑 API、做代理跳板这些用途，一个月的真实流量通常连 1TB 都到不了，这个量级完全够。要拿它做视频分发或大文件下载站，fair-share 下的实际速率才是瓶颈，先想清楚。

这也解释了一个常见的误判：拿“不限流量”当“不限速”买回去，发现跑不满标称带宽就以为被坑。买之前把这条读一遍，期望值就对了。

## 莫斯科机房快不快，看的不是机房到莫斯科的延迟

这组数字真正说明的是：莫斯科机房到莫斯科的快，和到你的用户所在城市的稳，是两件事。你要测的是“你的用户 → 莫斯科”这一跳，不是“莫斯科 → 莫斯科”。

具体怎么测？至少做三件事。

1. 找客服要当前莫斯科节点的测试 IP，用你用户所在地区的网络 ping 和 traceroute 一遍。第三方测评里列过 JustHost 各机房的测试 IP，但那些是几年前的记录，地址可能已经变了，直接问客服拿最新的更稳。
